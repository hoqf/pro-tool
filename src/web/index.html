Accounts

Tokens stay on this PC, encrypted with Windows, and are never shown again in full.

Need another account? Sign up on Discord in your browser (you solve the captcha yourself), then copy its token from Discord and paste it above.

Create account on Discord

Getting your token

  1. Open discord.com/app in your browser and log in to the account you want to use.
  2. Press F12 (or Ctrl+Shift+I) to open Developer Tools, then click the Network tab.
  3. In the filter box, type api. Then click any channel or server in Discord so requests show up.
  4. Click one of the requests to discord.com/api/… and open Headers.
  5. Under Request Headers, find authorization. Its value is the token - copy it.
  6. Paste it in the Token box here, give it a label and press Save to list.
Your token is a full login to that account. Never share it, and never paste code someone sends you into the browser console - that's how accounts get stolen. Logging out of Discord resets the token.

Saved accounts

Import a .txt with one token per line (or label|token). Tokens already saved are skipped.

Test mode

Start runs the name generator with your Search settings and lists the names, rated, on the Scan tab. No token is needed: nothing is checked with Discord, nothing is saved to your results or history, and no webhooks or notifications are sent. Applies the next time you press Start.

Updates

You have Pro Tool v-. It checks for updates each time it opens.

Minimize to background?

Pro Tool will keep running in the background. Scans carry on and found names still pop up as notifications. To bring it back, click the Pro Tool icon by the clock in the taskbar.
