# Changelog

Every version of Pro Tool. The app offers new versions automatically (**Update now / Later**).

## v2.1.7 - 2026-11-22
- Fixed: saved tokens and accounts now stay saved after closing or updating Pro Tool (add them once more after this update).

## v2.1.6 - 2026-11-22
- Tighter layout: every page fits the window without scrolling, and lists fill the space available.

## v2.1.5 - 2026-11-21
- Live scoreboard: turn on 'Keep a live scoreboard message' on the Webhook page and one message in your channel updates itself during a scan.

## v2.1.4 - 2026-11-21
- The project now lives at github.com/hoqf/pro-tool (older copies are redirected automatically).
- Fixed the counters briefly showing "-0" when a scan starts.
- Removed an unused window type (tidier code).

## v2.1.3 - 2026-11-21
- The update prompt shows right after start-up, and tries again if the internet isn't ready yet.
- Update checks always get the newest version info.

## v2.1.2 - 2026-11-21
- The default search is now random 4-letter names (letters a-z).

## v2.1.1 - 2026-11-21
- Cleaner build.

## v2.1.0 - 2026-11-21
- First version with automatic, signed updates.
- Word builder (prefixes, suffixes, either-side parts), picked at random.
- Name ratings out of 10, and a rating range for what to make.
- Test names window on the Scan tab, with ratings.
- Token alerts: yellow alert and highlight when a token stops working.
- Delays in milliseconds, smooth window resizing, full refresh-rate window.
